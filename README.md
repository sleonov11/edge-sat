# edge-sat — обнаружение кораблей на спутниковых снимках

Быстрый и масштабируемый пайплайн для детекции кораблей на спутниковых изображениях высокого разрешения. Реализованы два подхода к предварительной фильтрации тайлов перед запуском YOLO: классический признаковый (Gauss + DWT + DecisionTree) и нейросетевой (TinyCNN). Второй подход сокращает количество вызовов детектора в 17 раз при сопоставимом общем времени, что делает систему пригодной для реального времени на CPU.

## Особенности

- **Двухступенчатая фильтрация** – быстрый классификатор отсеивает пустые тайлы перед запуском тяжёлого детектора.
- **Два варианта классификатора**:
  - Классический: фильтр Гаусса → DWT Хаара → статистические признаки → решающее дерево.
  - Нейросетевой: лёгкая свёрточная сеть TinyCNN (92.4% точности).
- **Высокая производительность** – оптимизирован под CPU с использованием OpenMP, SIMD (AVX2) и стековых буферов.
- **Готовый YOLO‑воркер** – интеграция с ONNX Runtime, асинхронные очереди задач.
- **Поддержка больших изображений** – тайлинг с перекрытием, параллельная обработка.

## Требования

- **Компилятор**: g++ 11+ (поддерживает C++20/23, OpenMP)
- **Библиотеки**:
  - OpenCV 4.x (сборка с `pkg-config`)
  - ONNX Runtime (≥ 1.14)
- **Система**: Linux (тестировалось на Fedora)

## Сборка

### 1. Установите зависимости

```bash
# OpenCV
sudo dnf install opencv-devel    # или apt install libopencv-dev

# ONNX Runtime (скачайте预编译ный пакет или соберите из исходников)
# Например, распакуйте в third_party/onnxruntime
```

### 2. Клонируйте репозиторий

```bash
git clone https://github.com/your-org/edge-sat.git
cd edge-sat
```

### 3. Соберите классический пайплайн

```bash
g++ -std=c++23 -O3 -march=native -mtune=native -mprefer-vector-width=256 \
    -ffast-math -funroll-loops -fprefetch-loop-arrays -fomit-frame-pointer \
    -flto -fuse-linker-plugin -fopenmp \
    -Wl,--as-needed -s -pthread \
    -I include -I third_party/onnxruntime/include -L third_party/onnxruntime/lib \
    $(pkg-config --cflags opencv4) \
    main_bmp.cpp include/yolo/YoloWorker.cpp \
    -lonnxruntime $(pkg-config --libs opencv4) \
    -o edge-sat-bmp
```

### 4. Соберите пайплайн с TinyCNN

```bash
g++ -std=c++23 -O3 -march=native -mtune=native -mprefer-vector-width=256 \
    -ffast-math -funroll-loops -fprefetch-loop-arrays -fomit-frame-pointer \
    -flto -fuse-linker-plugin -fopenmp \
    -Wl,--as-needed -s -pthread \
    -I include -I third_party/onnxruntime/include -L third_party/onnxruntime/lib \
    $(pkg-config --cflags opencv4) \
    main_with_cnn.cpp include/yolo/YoloWorker.cpp include/classifier/TinyCNN.cpp \
    -lonnxruntime $(pkg-config --libs opencv4) \
    -o edge-sat-cnn
```

> **Примечание:** при необходимости замените пути к ONNX Runtime и модели YOLO.

## Запуск

```bash
# Установите путь к библиотекам ONNX
export LD_LIBRARY_PATH=third_party/onnxruntime/lib:$LD_LIBRARY_PATH

# Запуск с классическим пайплайном
./edge-sat-bmp <image.bmp> [model.onnx] [output.bmp]

# Запуск с TinyCNN
./edge-sat-cnn <image.bmp> [model.onnx] [output.bmp]
```

**Пример:**
```bash
./edge-sat-cnn Ship-water-2.bmp include/yolo/models/ships_yolo11l.onnx result.bmp
```

Вывод:
```
Image: 3128x2555
Total tiles: 130, positive: 29, time: 461 ms
Total detections: 55
Saved: result.bmp
```

## Пайплайн обработки

1. **Загрузка изображения** (BGR).
2. **Разбиение на тайлы** с перекрытием (размер и перекрытие задаются константами).
3. **Классификация каждого тайла**:
   - *Классический подход*: Grayscale → Гаусс → DWT → признаки → DecisionTree.
   - *TinyCNN*: прямое применение CNN к RGB‑тайлу (предварительно ресайз до 256×256).
4. **Положительные тайлы** передаются в очередь задач YOLO.
5. **YOLO‑воркер** выполняет инференс (ONNX Runtime) и возвращает детекции.
6. **Постобработка**: NMS, фильтрация по размеру, отрисовка на выходном изображении.

## Сравнение подходов

| Характеристика | Gauss + DWT + DecisionTree | TinyCNN |
|----------------|----------------------------|---------|
| Размер тайла   | 128×128                    | 256×256 |
| Всего тайлов (на 3128×2555) | 644              | 130     |
| Положительных тайлов (попало в YOLO) | 486 (75%) | 29 (22%) |
| Точность классификации | ~82% | 92.4% |
| Время префильтра (wall‑clock) | ~24 мс | ~60 мс |
| Время YOLO | ~410 мс | ~390 мс |
| **Общее время** | **~439 мс** | **~461 мс** |
| **Вызовов YOLO** | **486** | **29** |

**Вывод:** TinyCNN даёт практически такое же общее время, но в 17 раз реже вызывает YOLO, что критично для больших изображений и видеопотоков. Рекомендуется использовать именно его.

## Настройка

Все ключевые параметры задаются в `main.cpp` через `constexpr`:

```cpp
constexpr int TILE = 256;          // размер тайла
constexpr int OVERLAP = 16;        // перекрытие
constexpr float SIGMA = 1.5f;      // параметр Гаусса (для первого подхода)
```

Для изменения модели YOLO или CNN укажите путь в аргументах командной строки или измените значения по умолчанию в коде.

## Результаты

- **Классический пайплайн** – быстрый препроцессинг, но низкая селективность → много ложных срабатываний → YOLO перегружен.
- **Пайплайн с TinyCNN** – более медленный препроцессинг, но высокая точность → число вызовов YOLO падает в 17 раз → общее время остаётся на том же уровне при **гораздо лучшей масштабируемости**.

Достигнутые показатели (~0.45 с на кадр 3128×2555 на CPU) позволяют использовать систему в реальном времени при наличии GPU (ускорение до 5–10 раз) или в пакетном режиме.
